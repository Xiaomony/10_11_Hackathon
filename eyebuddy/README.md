# 瞳伴 EyeBuddy

> 一个插件，四种功能，一站解决视障人群上网的视觉障碍。

瞳伴 EyeBuddy 是一款面向视障人群的 Chrome 浏览器无障碍插件，基于 Manifest V3 架构，将 **AI 页面描述**、**文字朗读 + 高亮**、**鼠标十字准星**、**色盲校正** 四类功能整合为同一个插件，并通过协同设计让四功能彼此联动，而非单功能堆砌。

- **面向人群**：全盲 / 重度视障、低视力 / 老年、色盲 / 色弱
- **形态**：Chrome 浏览器插件（Manifest V3）
- **成本**：纯前端 + 免费 API，零硬件成本
- **AI 能力**：通义千问 Qwen-VL 多模态视觉模型

## 核心功能

| # | 功能 | 服务人群 | 技术 |
|---|------|----------|------|
| ① | **AI 页面描述** | 全盲 / 重度视障 | 通义千问 Qwen-VL 多模态视觉模型 |
| ② | **文字朗读 + 黄色高亮** | 低视力 / 老年 | Web Speech API + DOM 高亮 |
| ③ | **鼠标十字准星** | 低视力 / 老年 | 固定定位十字线 + 焦点环 |
| ④ | **色盲校正** | 色盲 / 色弱 | SVG feColorMatrix 滤镜（3 模式） |

### ① AI 页面描述

截取网页画面，调用通义千问 Qwen-VL 生成中文描述，再用语音合成播报给用户。不替代屏幕阅读器，而是增强它——让图片、图表、复杂布局能"听"到。

- 一键截图分析，描述整个页面布局和内容
- 通义千问 Qwen-VL，中文描述质量最佳
- 自动语音播报，与文字朗读功能联动
- 免费 100 万 tokens / 月，零成本

### ② 文字朗读 + 黄色高亮

悬停段落自动朗读，选中文字即时朗读。朗读时黄色高亮标记正在读的内容，让低视力用户清楚知道正在读哪段。

- 悬停 0.5 秒自动朗读段落文字
- 选中任意文字立即朗读
- 黄色背景 + 边框高亮正在朗读的元素
- 中文优先（zh-CN），0.9 倍语速，0.5X–1.5X 可调

### ③ 鼠标十字准星

全屏贯穿青色十字线，帮助低视力用户一眼定位鼠标位置。8px 空心圆环交汇点确保精准点击时不被线挡住。

- 亮青色 `#00FFFF`，网页中极少出现，天然高对比
- 2px 粗细 + 全屏贯穿，低于看不清高于挡视线
- 同色 4px 发光阴影，任何背景都可见
- 快捷键 + 控制面板双控开关

### ④ 色盲校正

SVG 色彩矩阵滤镜，三种模式一键切换，覆盖最常见色盲类型。纯 CSS 实现，零 API 调用，即时生效。

- 红绿色盲（protanopia）— 覆盖 99% 色盲者
- 绿色弱（deuteranomaly）— 最常见类型
- 蓝黄色盲（tritanopia）— 覆盖完整性
- 控制面板按钮切换，所见即所得

## 四功能协同设计

瞳伴不是 4 个单功能的堆砌，而是协同设计：

- **朗读时准星跟随** — 文字朗读高亮元素时，十字准星自动移动到元素中心
- **色盲模式 AI 补色** — 色盲校正开启时，AI 描述自动标注关键元素颜色（"红色按钮""绿色链接"）
- **AI 描述自动播报** — AI 生成描述后，若朗读功能已开启，自动用中文语音播报描述内容

## 安装与使用

### 方式一：加载完整插件（推荐，体验全部 4 功能）

1. 克隆或下载本仓库
   ```bash
   git clone https://github.com/Wayhhow/EyeBuddy.git
   ```
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 右上角开启**开发者模式**
4. 点击**加载已解压**，选择仓库内的 `插件/` 文件夹
5. 点击浏览器工具栏的瞳伴图标，完成首次引导
6. 在插件弹窗的**设置**中填入通义千问 API Key（[阿里云百炼平台免费申请](https://dashscope.console.aliyun.com/apiKey)，新用户 100 万 tokens 一次性免费额度，有效期 3 个月）

### 方式二：在线浏览展示页（无需安装）

直接在浏览器中打开仓库根目录的 `展示页.html`，可查看完整产品介绍 + 3 个交互式迷你 Demo：

- AI 描述模拟
- 文字朗读真实体验
- 色盲滤镜实时切换

> 展示页的迷你 Demo 不需要 API Key，开箱即用。

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 插件架构 | Chrome Manifest V3 | Service Worker + Content Script + Popup 三层 |
| AI 视觉 | 通义千问 Qwen-VL | 多模态视觉模型，中文描述质量最佳 |
| 语音合成 | Web Speech API | 浏览器内置 `SpeechSynthesisUtterance`，零成本 |
| 色盲校正 | SVG feColorMatrix | 3 模式色彩矩阵滤镜，纯 CSS 实现 |
| 网页截图 | `chrome.tabs.captureVisibleTab` | 系统级截图 API |
| 状态持久化 | `chrome.storage.local` | 用户设置跨会话保留 |
| 快捷键 | `chrome.commands` | 4 个全局快捷键 |

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 保存用户设置（功能开关、语速、API Key、色盲模式） |
| `activeTab` / `tabs` | 获取当前标签页信息、注入内容脚本 |
| `<all_urls>`（host_permissions） | 在任意网页上提供无障碍能力（朗读 / 准星 / 色盲 / 截图） |

> 插件不收集、不上传任何用户数据。API Key 仅存储在本地 `chrome.storage.local`，仅用于直接调用通义千问 API。

## 配置通义千问 API Key

AI 页面描述功能需要通义千问 API Key：

1. 访问 [阿里云百炼平台](https://dashscope.console.aliyun.com/apiKey)
2. 登录阿里云账号，点击**创建 API Key**
3. 复制 Key（形如 `sk-xxxxxxxx`）
4. 点击 Chrome 工具栏的瞳伴图标 → **设置** → 粘贴到"通义千问 API Key"输入框
5. 保存即可

**费用**：新用户 100 万 tokens 一次性免费额度，有效期 3 个月。日常使用每次描述约消耗 1–2 千 tokens，免费额度可描述约 500–1000 个页面。

## 开发与调试

### 本地开发

```bash
git clone https://github.com/Wayhhow/EyeBuddy.git
```

在 `chrome://extensions` 开启开发者模式，加载 `插件/` 文件夹。修改源码后点击插件卡片的"刷新"按钮即可热加载。

### 调试入口

| 调试对象 | 入口 |
|----------|------|
| Popup 页面 | 右键插件图标 → 检查弹出内容 |
| Content Script | 网页上 F12 → Sources → Content Scripts |
| Background Service Worker | `chrome://extensions` → 插件卡片 → Service Worker 链接 |

### 关键消息路由

插件采用消息通信架构，Popup / Content Script 不直接调用 Background 函数，统一通过 `chrome.runtime.sendMessage` 路由：

| 消息类型 | 触发 | 处理 |
|----------|------|------|
| `DESCRIBE_PAGE` | 用户点击 AI 描述 / `Ctrl+Shift+A` | Background 调用 Qwen-VL |
| `TOGGLE_CROSSHAIR` | 快捷键 / Popup 开关 | Content Script 切换准星 |
| `TOGGLE_READER` | 快捷键 / Popup 开关 | Content Script 切换朗读 |
| `CYCLE_COLORBLIND` | 快捷键 / Popup 开关 | Content Script 切换滤镜 |

## 背景与缘起

中国约有 **1700 万**视障用户、**6000 万以上**色盲色弱用户，他们上网时面临四类视觉障碍：看不见图、看不清文字、找不到鼠标、分不清颜色。现有工具各自为战——Be My Eyes 只做 AI 描述、NVDA 只做朗读、Chrome Color Enhancer 只做色盲滤镜，没有一个浏览器插件能同时覆盖这四类需求。

**瞳伴 EyeBuddy 是大赛中唯一面向视障人群、唯一浏览器插件形态、唯一覆盖 4 类视觉障碍的无障碍作品。**

> 数据来源：第二次全国残疾人抽样调查及中国残联后续引用数据；色觉异常流行病学统计（男性患病率约 5%–8%）。
