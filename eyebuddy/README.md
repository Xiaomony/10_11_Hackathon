# 瞳伴 EyeBuddy

> 一个插件，八种功能，一站解决视障人群上网的视觉障碍。

瞳伴 EyeBuddy 是一款面向视障人群的 Chrome 浏览器无障碍插件，基于 Manifest V3 架构，将 **AI 页面描述**、**文字朗读 + 高亮**、**鼠标十字准星**、**大光标与点击反馈**、**文字排版增强**、**阅读辅助线**、**色盲校正** 等能力整合为同一个插件，并通过协同设计让各功能彼此联动，而非单功能堆砌。

- **面向人群**：全盲 / 重度视障、低视力 / 老年、色盲 / 色弱
- **形态**：Chrome 浏览器插件（Manifest V3）
- **成本**：纯前端 + 免费 API，零硬件成本
- **AI 能力**：Agnes AI `agnes-3.0-flash` 多模态模型

## 核心功能

| # | 功能 | 服务人群 | 技术 |
|---|------|----------|------|
| ① | **AI 页面描述** | 全盲 / 重度视障 | Agnes AI 多模态模型 |
| ② | **文字朗读 + 黄色高亮** | 低视力 / 老年 | Web Speech API + DOM 高亮 |
| ③ | **鼠标十字准星** | 低视力 / 老年 | 固定定位十字线 + 焦点环 |
| ④ | **大光标与点击反馈** | 低视力 / 老年 | canvas 大箭头指针 + 点击涟漪 + 拖尾 |
| ⑤ | **文字排版增强** | 低视力 / 老年 | CSS 字号 / 行距 / 字距增强 |
| ⑥ | **阅读辅助线** | 低视力 / 阅读障碍 | 跟随鼠标的聚焦遮罩（纯 CSS） |
| ⑦ | **色盲校正** | 色盲 / 色弱 | SVG feColorMatrix 滤镜（3 模式） |

### ① AI 页面描述

优先把页面压缩为无障碍树文本发给 Agnes AI 生成中文描述（失败时回退整页截图走视觉模型），再用语音合成播报给用户。不替代屏幕阅读器，而是增强它——让图片、图表、复杂布局能"听"到。

- 一键分析，描述整个页面布局和内容
- 无障碍树文本优先，更快更省 token；截图视觉模型兜底
- 自动语音播报，与文字朗读功能联动
- Agnes AI 活动期免费额度，零成本

### ② 文字朗读 + 黄色高亮

悬停段落自动朗读，选中文字即时朗读。朗读时黄色高亮标记正在读的内容，让低视力用户清楚知道正在读哪段。

- 悬停 0.5 秒自动朗读段落文字
- 选中任意文字立即朗读
- 黄色背景 + 边框高亮正在朗读的元素
- 中文优先（zh-CN），0.9 倍语速，0.5X–1.5X 可调

### ③ 鼠标十字准星

全屏贯穿青色十字线，帮助低视力用户一眼定位鼠标位置。8px 空心圆环交汇点确保精准点击时不被线挡住。

- 亮青色 `#00FFFF`，网页中极少出现，天然高对比
- 2px 粗细 + 全屏贯穿，低于看不清高于挡视线
- 同色 4px 发光阴影，任何背景都可见
- 快捷键 + 控制面板双控开关

### ④ 大光标与点击反馈

原生鼠标指针太小、点没点上没反馈，是低视力用户最常见的高频痛点。此功能放大指针并在每次点击处给出可见反馈，纯本地实现，零 API 调用。

- canvas 现画 48px 大箭头（白填充 + 黑描边），任何背景上都醒目
- 点击处扩散粉色涟漪，明确"点到了"
- 轻微青色拖尾，帮助捕捉鼠标移动轨迹
- 快捷键 + 控制面板双控开关

### ⑤ 文字排版增强

不改变页面结构，仅注入一段 CSS：放大字号、加宽行距与字距，让整页文字更容易阅读。对长文、论坛、文档类页面效果最明显。

- 根字号放大 12%，正文行高提升到 1.8
- 增加字距与词距，减少文字粘连
- 纯 CSS 注入，不修改页面 DOM，一键开关

### ⑥ 阅读辅助线

跟随鼠标的聚焦遮罩：光标上下区域半透明暗化，中间保留一条清晰阅读窗口，帮用户专注当前行、避免串行。

- 上下双向遮罩，突出当前阅读行
- 两条黄色参考线标出阅读窗口边界
- 纯 DOM/CSS 实现，零 API 调用

### ⑦ 色盲校正

SVG 色彩矩阵滤镜，三种模式一键切换，覆盖最常见色盲类型。纯 CSS 实现，零 API 调用，即时生效。

- 红绿色盲（protanopia）— 覆盖 99% 色盲者
- 绿色弱（deuteranomaly）— 最常见类型
- 蓝黄色盲（tritanopia）— 覆盖完整性
- 控制面板按钮切换，所见即所得

## 功能协同设计

瞳伴不是单个功能的堆砌，而是协同设计：

- **朗读时准星跟随** — 文字朗读高亮元素时，十字准星自动移动到元素中心
- **色盲模式 AI 补色** — 色盲校正开启时，AI 描述自动标注关键元素颜色（"红色按钮""绿色链接"）
- **AI 描述自动播报** — AI 生成描述后，若朗读功能已开启，自动用中文语音播报描述内容

## 安装与使用

1. 克隆或下载本仓库
   ```bash
   git clone https://github.com/Xiaomony/10_11_Hackathon.git
   ```
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 右上角开启**开发者模式**
4. 点击**加载已解压**，选择仓库内的 `插件/` 文件夹
5. 点击浏览器工具栏的瞳伴图标，完成首次引导
6. 在插件弹窗的**设置**中填入 Agnes AI API Key（[Agnes AI 平台免费申请](https://platform.agnes-ai.cn/)，活动页 https://agnes-ai.cn/campaign ，当前 `agnes-3.0-flash` 多模态模型免费额度）

## 键盘快捷键

视障用户重度依赖键盘，4 个默认快捷键覆盖最常用的 AI 与定位操作：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+X` | 切换鼠标十字准星 |

以下命令未占用默认快捷键，可在 `chrome://extensions/shortcuts` 页面自行绑定（Chrome 限制最多 4 个默认快捷键）：

| 命令 | 功能 |
|------|------|
| 开关阅读辅助线 | 打开 / 关闭阅读辅助线 |
| 开关文字排版增强 | 打开 / 关闭文字排版增强 |
| 开关大光标与点击反馈 | 打开 / 关闭大光标与点击反馈 |

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 保存用户设置（功能开关、语速、API Key、色盲模式） |
| `activeTab` / `tabs` | 获取当前标签页信息、注入内容脚本 |
| `<all_urls>`（host_permissions） | 在任意网页上提供无障碍能力（朗读 / 准星 / 大光标 / 排版增强 / 阅读辅助线 / 色盲 / 截图） |

> 插件不收集、不上传任何用户数据。API Key 仅存储在本地 `chrome.storage.local`，仅用于直接调用 Agnes AI API。

## 配置 Agnes AI API Key

AI 页面描述与图片悬停描述功能需要 Agnes AI API Key：

1. 访问 [Agnes AI API 平台](https://platform.agnes-ai.cn/)（免费额度活动页：https://agnes-ai.cn/campaign ）
2. 注册 / 登录账号，在开发者控制台生成 API Key
3. 复制 Key
4. 点击 Chrome 工具栏的瞳伴图标 → **设置** → 粘贴到"Agnes AI API Key"输入框
5. 保存即可

**接口与模型**：插件通过 OpenAI 兼容接口 `https://api.agnes-ai.cn/v1/chat/completions` 调用多模态模型 `agnes-3.0-flash`（截图以 JPEG Data URL 发送，已实测支持 base64 图像输入）。当前该模型在免费活动期内，按量价格为 ¥0；接口地址与模型名集中在 `插件/background.js` 顶部的 `AGNES_API_URL`、`AGNES_MODEL` 两个常量，如需切换其他 OpenAI 兼容服务商（如阿里云百炼、硅基流动、智谱等），修改这两个常量即可。

**故障排查**：调用失败时，页面浮层会直接显示具体原因——401 表示 Key 无效，404 表示模型名或地址错误，429 表示限流或额度用尽，详细日志见扩展卡片的 Service Worker 控制台。

### 本地开发

```bash
git clone https://github.com/Wayhhow/EyeBuddy.git
```

在 `chrome://extensions` 开启开发者模式，加载 `插件/` 文件夹。修改源码后点击插件卡片的"刷新"按钮即可热加载。

### 调试入口

| 调试对象 | 入口 |
|----------|------|
| Popup 页面 | 右键插件图标 → 检查弹出内容 |
| Content Script | 网页上 F12 → Sources → Content Scripts |
| Background Service Worker | `chrome://extensions` → 插件卡片 → Service Worker 链接 |

### 关键消息路由

插件采用消息通信架构，Popup / Content Script 不直接调用 Background 函数，统一通过 `chrome.runtime.sendMessage` 路由：

| 消息类型 | 触发 | 处理 |
|----------|------|------|
| `DESCRIBE_PAGE` | 用户点击 AI 描述 / `Ctrl+Shift+A` | Background 调用 Agnes AI |
| `TOGGLE_CROSSHAIR` | 快捷键 / Popup 开关 | Content Script 切换准星 |
| `TOGGLE_READER` | 快捷键 / Popup 开关 | Content Script 切换朗读 |
| `CYCLE_COLORBLIND` | 快捷键 / Popup 开关 | Content Script 切换滤镜 |

## 背景与缘起

中国约有 **1700 万**视障用户、**6000 万以上**色盲色弱用户，他们上网时面临四类视觉障碍：看不见图、看不清文字、找不到鼠标、分不清颜色。现有工具各自为战——Be My Eyes 只做 AI 描述、NVDA 只做朗读、Chrome Color Enhancer 只做色盲滤镜，没有一个浏览器插件能同时覆盖这四类需求。

**瞳伴 EyeBuddy 是大赛中唯一面向视障人群、唯一浏览器插件形态、唯一覆盖 4 类视觉障碍的无障碍作品。**

> 数据来源：第二次全国残疾人抽样调查及中国残联后续引用数据；色觉异常流行病学统计（男性患病率约 5%–8%）。
