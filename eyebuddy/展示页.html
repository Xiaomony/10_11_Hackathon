问题

三类人，四个困境

中国近亿视障群体被数字鸿沟隔绝，现有工具各自为战。

看不见图

全盲 / 重度视障 · 1700万

屏幕阅读器只能读文字，遇到图片、图表、复杂布局就"哑巴"了。Chrome 内置 AI 描述依赖 Google 服务，国内不可用。

看不清文字

低视力 / 老年 · 数千万

看得见屏幕但看不清文字，想听内容却没有朗读工具。现有读屏软件朗读时没有高亮标记，不知道正在读哪段。

找不到鼠标

低视力 / 老年 · 数千万

看得见屏幕但看不清，鼠标一不留神就丢在角落再也找不回来。Windows 放大镜太粗糙，没有专门的定位辅助。

分不清颜色

色盲 / 色弱 · 6000万+

红绿不分、图表颜色无意义、表单验证色看不出。Chrome 色盲插件只是纯滤镜，没有 AI，没有鼠标增强。

功能

四种功能，一个插件

不是多个插件的拼凑，是深度整合的无障碍体验。

服务全盲 / 重度视障

AI 页面描述

截取网页画面，通义千问 Qwen-VL 生成中文描述，语音播报给用户。不替代屏幕阅读器，而是增强它——让图片能"听"到。

  • 一键截图分析，描述整个页面布局和内容
  • 通义千问 Qwen-VL，中文描述质量最佳
  • 自动语音播报，与文字朗读功能联动
  • 免费 100 万 tokens/月，零成本

服务全盲 / 低视力

文字朗读 + 高亮

悬停段落自动朗读，选中文字即时朗读。朗读时黄色高亮标记正在读的内容，让用户清楚地知道正在读哪段文字。

  • 悬停 0.5 秒自动朗读段落文字
  • 选中任意文字立即朗读
  • 黄色背景 + 边框高亮正在朗读的元素
  • Web Speech API，浏览器内置零成本
  • 中文优先（zh-CN），0.9 倍语速

服务低视力 / 老年

鼠标十字准星

全屏贯穿青色十字线，帮助低视力用户一眼定位鼠标位置。8px 空心圆环交汇点确保精准点击时不被线挡住。

  • 亮青色 #00FFFF，网页中极少出现，天然高对比
  • 2px 粗细 + 全屏贯穿，低于看不清高于挡视线
  • 同色 4px 发光阴影，任何背景都可见
  • 快捷键 Ctrl+Shift+X + 控制面板双控开关
服务色盲 / 色弱

色盲校正

SVG 色彩矩阵滤镜，三种模式一键切换，覆盖最常见色盲类型。纯 CSS 实现，零 API 调用，即时生效。

  • 红绿色盲（protanopia）— 覆盖 99% 色盲者
  • 绿色弱（deuteranomaly）— 最常见类型
  • 蓝黄色盲（tritanopia）— 覆盖完整性
  • 控制面板按钮切换，所见即所得

商业价值
