🖼️ 图片悬停描述 · 测试页

使用方法：加载插件后，开启 popup 里的「图片悬停描述」开关，然后把鼠标悬停在下面每张图上停 1 秒左右。
标注说明：无需 API Key = 现在就能完整验证；需要 Key = 要等视觉模型 Key 才能出 AI 文本（但无 Key 时的报错提示也值得验证）。

用例 1：有 alt 的图片无需 API Key

alt="一只橘猫坐在窗台上晒太阳"

预期：悬停后直接弹出「🖼️ 图片：一只橘猫坐在窗台上晒太阳」；若同时开了文字朗读，会自动读出来。全程不消耗 API。

用例 2：无 alt 但有 aria-label 的图片无需 API Key

aria-label="日出时的山间湖泊，湖面有薄雾"

预期：和用例 1 相同，直接读出 aria-label 内容，不耗 API。

用例 3：无任何替代文本的图片需要 Key

这正是视障用户最常遇到的"黑洞图"——读屏器只会说"图片"两个字

预期：① 未配 Key 时弹出「⚠️ 请先在插件设置中配置 API Key」（说明错误链路正常）；② 配好 Key 后弹出 AI 对这张图的中文描述并自动朗读。

用例 4：页面上的装饰小元素无需 API Key

一个 30×30 的灰色小方块（页面上大量装饰图标属于这类）

预期：悬停无任何反应（插件自动过滤小于 40px 的元素，避免骚扰）。
