# 瞳伴 EyeBuddy · 无障碍浏览器插件

南科大无障碍公益黑客松作品。给视障/低视力用户的浏览器"眼睛"：AI 描述页面、悬停朗读图片和文字、十字准星、大光标、排版增强、阅读辅助线、色盲校正、B 站弹幕总结。

---

## 🧩 安装插件（3 步）

1. 克隆或下载本仓库，Chrome 地址栏输入 `chrome://extensions`，右上角开启**开发者模式**
2. 点击**加载已解压的扩展程序**，选择本仓库的 `EyeBuddy\插件` 文件夹
3. 点击浏览器工具栏的瞳伴图标，完成首次引导，按需开启功能

## 🔑 配置 API Key（AI 功能需要）

AI 页面描述、图片悬停描述、弹幕总结依赖 Agnes AI（活动期免费）：

1. 访问 [Agnes AI 平台](https://platform.agnes-ai.cn/) 注册，在开发者控制台生成 API Key
2. 瞳伴弹窗 → ⚙️ **设置** → 粘贴 Key 保存

> 没有 Key 也能体验：设置里勾选**演示模式**，AI 功能会返回预置描述。

## ⌨️ 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+A` | AI 描述当前页面 |
| `Ctrl+Shift+X` | 切换鼠标十字准星 |
| `Ctrl+Shift+R` | 开关文字朗读 |
| `Ctrl+Shift+C` | 循环切换色盲校正模式 |
